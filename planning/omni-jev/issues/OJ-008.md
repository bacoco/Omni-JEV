# [P1] Compare a small cross-attention decision module with MaxSim

**Planning ID:** `OJ-008`  
**Priority:** P1  
**Status:** Proposed; no experiment results yet.

## Goal

Test whether a more expressive interaction helps relational conditions at an acceptable incremental cost. Do not assume attention is necessarily better than a trained MaxSim baseline.

## Scope

- Let question/option states read a fixed, reusable multimodal memory through a small attention module.
- Retain reliable modality and time/spatial metadata, with explicit masking and question independence.
- Compare variants with and without the global state feature; avoid changing several factors at once.
- Match backbone, data, initialization policy, and training protocol; disclose differences in head size or tuning budget.
- Profile per-question work and validate true memory reuse rather than only batched execution.
