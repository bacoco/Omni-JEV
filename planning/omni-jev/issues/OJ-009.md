# [P1] Build staged supervised fine-tuning and reproducibility tooling

**Planning ID:** `OJ-009`  
**Priority:** P1  
**Status:** Proposed; no experiment results yet.

## Goal

Turn head-level experiments into reproducible training runs and determine whether adapting the pretrained state encoder is worthwhile. Reinforcement learning and distillation are not prerequisites.

## Dependencies

<!-- dependencies:start -->

## Scope

- Standardize losses for binary, exclusive-choice, and ordinal questions; log task weights and all trainable parameter groups.
- Run frozen-backbone, parameter-efficient/partial adaptation, and more extensive fine-tuning only under an explicit compute budget.
- Invalidate/recompute detached feature caches whenever producing weights change.
- Add checkpoint manifests, seeds, optimizer/training settings, environment locks, resume tests, and deterministic evaluation where supported.
- Use reviewed contrastive/decision counterexamples and audit any synthetic or teacher labels; keep all related sources within one split.

## Acceptance criteria

- [ ] A tiny overfit/debug run, resume check, and full evaluation command are documented.
- [ ] E08 attributes improvements to a specific adaptation stage with its compute cost.
- [ ] Failure modes and data exclusions are recorded, including false-negative collisions.
- [ ] RL or teacher distillation is a separately justified follow-up experiment, not an unsupported default.

## Evidence to attach

A concise implementation/experiment report, pinned revisions, commands, results or failure reasons, and any changed assumptions. Do not present the plan itself as a successful run.
