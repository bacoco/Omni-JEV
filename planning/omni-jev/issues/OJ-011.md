# [P1] Calibrate outputs and define evidence-aware abstention

**Planning ID:** `OJ-011`  
**Priority:** P1  
**Status:** Proposed; no experiment results yet.

## Goal

Make uncertainty an evaluated output property. Softmax, sigmoid, and proper scoring rules alone are not evidence of calibrated probabilities on the deployment distribution.

## Dependencies

<!-- dependencies:start -->
- [OJ-009](OJ-009.md)
- [OJ-010](OJ-010.md)
<!-- dependencies:end -->

## Scope

- Fit calibration using only the dedicated calibration split and compare suitable methods without using final test labels.
- Report probability quality, reliability curves, and risk-coverage by type, modality, domain, and predicate family.
- Define application thresholds and review policies after error costs are specified; keep them out of hidden model defaults.
- Keep status for missing/unsupported evidence distinct from low confidence in an otherwise valid answer.
- Document the returned confidence semantics and any limits of compatibility with the Jev interface.

## Acceptance criteria

- [ ] Accepted-decision error and review rate are jointly reported at declared operating points.
- [ ] Calibration artifacts are versioned and included in serving provenance.
- [ ] No unsupported fourth decision primitive is introduced and no missing audio becomes a confident no.
- [ ] Tests include OOD examples, ambiguous rubric levels, and changes in candidate count.
