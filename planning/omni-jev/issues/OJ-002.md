# [P0] Specify and test Noul, Choice, and Score contracts

**Planning ID:** `OJ-002`  
**Priority:** P0  
**Status:** Proposed; no experiment results yet.

## Goal

Preserve the three Jev-style output families while defining an independent, versioned Omni-JEV interface. This issue is about semantics and invariants, not implementing a generation-and-JSON-parsing workaround.

## Dependencies

<!-- dependencies:start -->
None.
<!-- dependencies:end -->

## Scope

- Define state manifests, request-local question IDs, typed questions, natural-language option descriptions, and ordered rubric levels.
- Define Noul as the estimated probability of yes; Choice as one option and its question-local distribution; Score as the expected index of described levels plus the full distribution.
- Specify separate evidence/status metadata for missing inputs, unsupported modalities, errors, and abstention. Do not coerce unavailable audio to a negative result.
- Document the confidence method and exact compatibility boundaries; do not substitute an undocumented max-probability measure for Jev confidence.
- Define masks, question isolation, candidate-ID uniqueness, validation failures, and multi-label composition as independent binary questions.

## Acceptance criteria

- [ ] Request/response schemas and synthetic examples cover all three types without implying that the examples came from a trained model.
- [ ] Tests reject malformed rubrics, empty candidate sets, duplicate IDs, and mismatched probability lengths.
- [ ] Tests cover valid probability sums, expected-score arithmetic, option reorder behavior, padding, and independent question grouping.
- [ ] The API distinguishes answer probability, ordinal position, confidence, evidence availability, and application policy.
