# [P1] Implement discriminatively trained ColBERT-style late interaction

**Planning ID:** `OJ-007`  
**Priority:** P1  
**Status:** Proposed; no experiment results yet.

## Goal

Reuse token projection, masking, normalization, and MaxSim infrastructure as a decision baseline. The new objective is question-answer supervision, not merely retrieval ranking plus a threshold.

## Dependencies

<!-- dependencies:start -->
- [OJ-006](OJ-006.md)
<!-- dependencies:end -->

## Scope

- Build a reference MaxSim scorer using independently encoded condition tokens and selected state vectors.
- Adapt colpali_engine components where compatible and establish numerical parity against a simple implementation.
- Train projections/scorers on the three typed objectives with backbone frozen first; record whether the condition branch is also updated.
- Handle multiple valid positives and unknown labels; do not treat all other batch states as negatives.
- Compare state-global, ordered segment, and token-memory variants without mixing backbone changes into the same ablation.

## Acceptance criteria

- [ ] Masking, empty-valid-input handling, normalization, and gradient tests pass.
- [ ] Evaluation includes negation, wrong-region binding, and reordered/offset events.
- [ ] Results separate calibration-only adaptation from representation/head training.
- [ ] The implementation does not require a vector database for a supplied-state decision.
