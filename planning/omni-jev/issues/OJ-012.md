# [P2] Measure compression, cache economics, and compact alternatives

**Planning ID:** `OJ-012`  
**Priority:** P2  
**Status:** Proposed; no experiment results yet.

## Goal

Optimize only after an uncompressed reference exists. Test whether fewer vectors, narrower vectors, reduced precision, or a compact domain-specific model preserves the useful decision behavior.

## Scope

- Vary token/segment count, feature width, and precision separately; compare simple pooling with a learned bottleneck.
- Keep full-resolution/no-additional-compression references and evaluate difficult spatial/temporal predicates, not only global averages.
- Measure decode, first-state encode, and 1/10/100-question incremental costs where feasible, with and without valid cache reuse.
- Evaluate ColModernVBERT or another audited compact document model separately; consider distillation only with reviewed targets and an established reference.
- Report peak memory, serialized cache size, latency distributions, accepted-error coverage, and hardware/input settings.

## Acceptance criteria

- [ ] Compression curves show matched-error or matched-coverage comparisons rather than only compression ratios.
- [ ] Cache invalidation and model-revision safety tests pass.
- [ ] An architecture decision selects a measured configuration or explicitly retains the uncompressed model.
- [ ] No generic claim of "BERT speed" or borrowed Jev latency is used in the report.

## Evidence to attach

A concise implementation/experiment report, pinned revisions, commands, results or failure reasons, and any changed assumptions. Do not present the plan itself as a successful run.
