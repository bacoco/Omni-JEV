# [P0] Establish global-embedding, text-pipeline, and existing-model baselines

**Planning ID:** `OJ-005`  
**Priority:** P0  
**Status:** Proposed; no experiment results yet.

## Goal

Measure how much the task already benefits from upstream models before adding a rich multimodal decision head. Separate unchanged embedding retrieval, supervised global-feature scoring, and existing task-capable models.

## Dependencies

## Scope

- Evaluate native state/text embeddings with task descriptions and an explicitly documented similarity/selection rule.
- Add a supervised global-feature scorer without changing the backbone; distinguish this from fitting calibration or thresholds.
- Evaluate OCR-plus-text-decision and transcription-plus-text-decision pipelines only for predicates their observations can address, including their full preprocessing cost.
- Admit an existing visual/omni decision model or structured-output model after its availability audit; mark inaccessible models as exclusions.
- Keep the same split, label definitions, media inputs, and reporting protocol for all comparisons.

## Acceptance criteria

- [ ] Baseline predictions, scripts, model manifests, and per-family metrics are reproducible.
- [ ] Runs report preprocessing errors, output validation failures, and missing-modality behavior.
- [ ] No retrieval leaderboard number is substituted for a project decision result.
- [ ] Cold/warm encoding, incremental questions, and memory measurements are separated.

## Evidence to attach

A concise implementation/experiment report, pinned revisions, commands, results or failure reasons, and any changed assumptions. Do not present the plan itself as a successful run.
