# [P0] Build the leakage-resistant dataset and evaluation protocol

**Planning ID:** `OJ-003`  
**Priority:** P0  
**Status:** Proposed; no experiment results yet.

## Goal

Create a benchmark that can distinguish semantic relevance from correct decisions. Include source-grouped splits, novel predicates, clear evidence availability, and task-specific measurements before tuning architecture choices.

## Dependencies

<!-- dependencies:start -->
- [OJ-002](OJ-002.md)
<!-- dependencies:end -->

## Scope

- Define a pilot spanning global image content, document detail, spatial binding, spoken content, environmental audio, ordered video actions, audiovisual correspondence, and rubric scoring.
- Split by source document, video, session, speaker, and template as appropriate before creating crops, offsets, or paraphrases.
- Reserve a separate calibration split and hold out whole predicate/label families for generalization. Record target languages rather than assuming English-only behavior.
- Write annotation guidelines with concrete rubric levels, evidence sufficiency, inter-rater review, and label/source provenance.
- Implement decision, calibration, risk-coverage, temporal, and full-latency metrics; register selection criteria before reading the final test results.

## Acceptance criteria

- [ ] A versioned data specification, reviewed pilot, split IDs, and leakage checks are available.
- [ ] Controlled counterexamples include negation, wrong spatial association, missing input, reordered events, and shifted audio.
- [ ] Grouped uncertainty estimates and per-family reporting are supported.
- [ ] No numerical deployment threshold or dataset size is invented without the intended application and compute context.

## Evidence to attach

A concise implementation/experiment report, pinned revisions, commands, results or failure reasons, and any changed assumptions. Do not present the plan itself as a successful run.
